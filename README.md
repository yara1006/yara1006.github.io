# Hannah 的个人主页 · Personal Portfolio

Hannah (杨韩冰) 的个人主页 - AI Product Manager Portfolio

## 预览效果

学术风格 + 清晰排版 + **Dark Mode** + **中英文切换**

## 网站结构

- `index.html` - 主页
- `_competitions/` - 比赛记录（Markdown 文件）
- `_articles/` - 想法记录（Markdown 文件）
- `competitions/index.html` - 比赛列表页（Jekyll 模板）
- `articles/index.html` - 想法记录列表页（Jekyll 模板）
- `admin/` - Decap CMS 管理后台
- `_layouts/` - Jekyll 布局模板

## 技术栈

- [Jekyll](https://jekyllrb.com/) - 静态站点生成器
- GitHub Pages - 托管
- [Decap CMS](https://decapcms.org/) - 内容管理后台

## 自定义修改

- `_competitions/*.md` - 编辑比赛记录内容
- `_articles/*.md` - 编辑想法记录文章
- `_config.yml` - Jekyll 配置
- `index.html` - 主页内容
